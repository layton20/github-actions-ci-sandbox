# ASP.NET Core CI/CD Practice

This is a simple ASP.NET Core web app I created to learn and practice CI/CD using GitHub Actions.

The goal of this project is to get hands-on experience with:
- GitHub Actions (using YAML)
- Running build and test steps automatically on push or pull request
- (Optional) Deploying to Azure App Service

I'll be updating this as I learn more. Right now the pipeline runs on every push to `main` and checks that the app builds and tests pass.

This is part of my learning journey and a way to demonstrate basic understanding of CI/CD as a .NET developer.
